# Student Grievance Redressal System

A Python-based console application for submitting and managing student grievances.

## Features

- Submit a grievance
- View submitted grievances
- Admin login
- Update grievance status
- Add admin remarks
- Unique grievance IDs

## Technologies Used

- Python
- Functions
- Lists
- Dictionaries
- Loops
- Conditional Statements

## How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Run the program:

```bash
python SGRS.py
